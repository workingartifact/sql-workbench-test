WORKBENCH HELP

Using the SQL Workbench

Hearth & Holler is a fictional two-store grocery business. This CLASSROOM edition covers January–March 2025. Everything executes in your browser, with no database account or server connection.

Choose exactly what to run

Run current · Ctrl/⌘ + Enter
The statement containing your cursor. Semicolons inside strings and comments do not split statements.
Run selection · Ctrl/⌘ + Shift + Enter
Only the highlighted text. Select complete SQL statements.
Run all · Alt + Enter
Up to 12 statements in order. Stops on the first error; earlier successful results remain labeled.

DuckDB SQL, not MySQL

SELECT, joins, CTEs and window functions work here. Use STRFTIME for date formatting and EXTRACT(ISODOW FROM date) - 1 for a Monday-zero weekday. MySQL ENUM order and some NULL behavior differ. Queries are never automatically translated.

Results and exports

Pagination only changes the display. CSV and JSON export every row of the selected complete result. Numbers are retained as exact text; NULL stays distinct. JSON uses column metadata plus row arrays, preserving duplicate column names. CSV uses unquoted \N for NULL. Import identifiers as text in spreadsheets. Exact CSV is the default. Enable Spreadsheet-safe to prefix formula-like text and headers with an apostrophe; this deliberately changes those text values. The same choice applies to Copy CSV. JSON always preserves exact values. Spreadsheet import behavior varies; review import settings and use JSON for a lossless round trip.

A bounded, read-only workspace

The database is opened read-only. File access, extensions, settings and write commands are disabled. Each run allows 100,000 rows or approximately 20 MiB of result values, with a 30-second query timeout. Oversized results fail explicitly instead of producing a partial export. Add LIMIT or aggregate. Cancel stops this page’s SQL worker; use Reload database to recover.

Your draft is saved only in this browser when storage is available. Reset editor can be undone with Ctrl/⌘ + Z. Reload database retains your draft. Tested locally in Windows Chrome and Pixel 9 Android Chrome. Other devices and browsers may have different memory limits.
